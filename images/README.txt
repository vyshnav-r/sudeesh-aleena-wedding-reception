PHOTOS: EVERY IMAGE ON THE INVITATION, SORTED BY SECTION
========================================================
To change a photo: put your new photo in the same folder with the SAME FILE NAME (and keep it .jpg),
replacing the old one. Nothing else needs to change. Every slot has its own file, so changing one
photo never changes another section.

Tips
- Save as .jpg. About 1000 pixels wide is plenty; keep each file under about 300 KB so the page stays fast.
- Faces near the middle and upper half of the photo work best inside the arch shapes.
- The page crops each photo to fit its shape, and the crop is centred. If a face gets cut off, tell your
  developer and the focus point (object-position) of that one photo can be adjusted.
